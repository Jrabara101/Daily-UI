# 🎫 The Velocity Ticket: Smart Coupon System

Welcome to the **Velocity Ticket**! This project is a beautiful, interactive digital coupon designed to give online shoppers a premium and engaging experience when claiming a discount.

Rather than looking like a generic web form, the coupon is styled to look and feel like a high-end physical ticket, complete with virtual side cutouts and a dashed tear-off perforation.

---

## 🌟 Key Features

### 1. ⏱️ Active Countdown Timer
To create a friendly sense of urgency, the ticket displays a real-time countdown timer starting at **24 hours**. 
- It updates second-by-second to show exactly how much time is left to claim the offer.
- If the timer runs out, the ticket gracefully updates to let the visitor know the offer has expired.

### 2. ⚡ One-Click Copying
No need to highlight, select, and copy code manually. 
- Visitors can simply click anywhere on the ticket to instantly copy the discount code (`friends-of-pop`) to their computer or phone's clipboard.
- The ticket changes its text to **"COPIED!"** to confirm the action succeeded.

### 3. 🎉 Celebration Animation
When a user successfully copies the code, the screen celebrates with a dynamic **confetti burst** animation, making the simple act of claiming a discount feel rewarding and fun.

### 4. 🧠 Smart Memory
The ticket has a "memory" system built-in:
- **Remembers Expiration:** If a user leaves the website and returns later, the timer will continue counting down from the exact time they first visited (rather than restarting at 24 hours).
- **Remembers Claims:** If a user has already copied the code, the ticket will remember this and remain in a "Claimed" state on future visits, preventing accidental duplicate clicks.

### 5. ♿ Friendly for Everyone
The ticket is designed to be fully usable by everyone:
- It can be navigated entirely using a keyboard (e.g., using the **Space** or **Enter** keys).
- It is compatible with screen readers, announcing clear instructions to visually impaired users.

---

## 🎨 Design Aesthetics
- **Physical Ticket Look**: Features curved notches cut out of the left and right sides to look like a physical ticket stub.
- **Perforated Separator**: An animated dashed line separates the main discount information from the promo code itself, inviting the user to "tear" it off by clicking.
- **Premium Colors & Effects**: Utilizes subtle shadows, a gentle background glow, and smooth animations when hovering or clicking, giving the page a modern, high-quality look.
