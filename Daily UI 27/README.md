# Daily UI 27 - Profile Dropdown

## Description
This project is a modern, interactive Profile Dropdown menu created as part of the Daily UI challenge (Day 27). It features a sleek, animated user interface with a profile picture and a dropdown menu that displays notifications for different sections like Inbox, Calendar, and Tasks.

## Features
- **Modern UI Design**: Uses a vibrant gradient background and an elegant card-based layout.
- **Interactive Animations**: Includes smooth hover effects, a pulse animation for notification badges, and a custom click feedback message.
- **Responsive Layout**: Adapts gracefully to smaller screen sizes, making it mobile-friendly.
- **Accessibility**: Supports basic keyboard navigation (Up/Down arrows to move between menu items, Enter to select).

## Technologies Used
- **HTML5**: For semantic structure.
- **CSS3**: For styling, utilizing CSS gradients, Flexbox, custom transitions, and keyframe animations for a polished look.
- **Vanilla JavaScript**: For click handling, dynamic feedback messages, and keyboard accessibility.

## How to Run
Simply open the `index.html` file in any modern web browser to view and interact with the profile dropdown.
